# Cuong Chien Online

Game 2D MMORPG dùng Godot và Supabase.

- Android package: `com.cuongchien.online`
- Kiến trúc Android: `arm64-v8a`
- Màn hình khởi chạy: `Auth.tscn`

## Tạo APK
Sau khi tải toàn bộ nội dung ZIP này lên nhánh `main` của repository, mở tab **Actions** và chạy workflow **Build Android APK**. APK được lưu trong artifact `CuongChienOnline-Android-APK`.

## Lưu ý
Workflow hiện tạo APK debug để cài thử trên thiết bị. Đây chưa phải bản phát hành Google Play đã ký bằng khóa upload/release riêng.
